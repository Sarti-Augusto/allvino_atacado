# Plan 02-01: Painel Admin & CRUD de Vinhos

## Goal
Implementar a interface de gerenciamento de vinhos, incluindo listagem administrativa completa (com busca, paginação, toggles rápidos e ordenação), formulário reutilizável de cadastro/edição (com upload de imagem para o Supabase Storage) e suas respectivas Server Actions de banco de dados.

- ADMIN-02
- ADMIN-03
- ADMIN-04
- ADMIN-05
- ADMIN-06
- ADMIN-07
- ADMIN-08

  <read_first>

    - src/app/actions/wines.ts

  <action>
    Modificar `src/app/actions/wines.ts` para adicionar as Server Actions administrativas:
    1. `fetchAdminWinesServer(search: string)`: busca vinhos (ativos e inativos), ordenados por `destaque` desc, `ordem` asc, `nome` asc.
    2. `toggleWineActiveServer(id: string, active: boolean)`: atualiza o campo `ativo` no Supabase.
    3. `toggleWineFeaturedServer(id: string, featured: boolean)`: atualiza o campo `destaque` no Supabase.
    4. `updateWineOrderServer(id: string, order: number)`: atualiza o campo `ordem` no Supabase.
    5. `deleteWineServer(id: string)`: deleta o registro do vinho.
    6. `uploadWineImageAction(formData: FormData)`: recebe arquivo via FormData, lê os bytes, gera nome do arquivo renomeando-o para UUID + extensão original, faz upload para o bucket `wine-images` do Supabase e retorna a URL pública.
    7. `createWineServer(data: any)`: insere um novo vinho.
    8. `updateWineServer(id: string, data: any)`: atualiza um vinho.
    Garanta a presença de `'use server';` no início do arquivo se necessário, ou exporte funções assíncronas padrão.
  </action>
  <acceptance_criteria>
    - `src/app/actions/wines.ts` exporta as novas funções: `fetchAdminWinesServer`, `toggleWineActiveServer`, `toggleWineFeaturedServer`, `updateWineOrderServer`, `deleteWineServer`, `uploadWineImageAction`, `createWineServer` e `updateWineServer`.
  </acceptance_criteria>
</task>
