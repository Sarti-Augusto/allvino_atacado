# Plan 04-01: Geração de QR Code e Compartilhamento Inteligente

## Goal
Implementar a geração e exibição local de QR Codes (SVGs gerados via cliente) na ficha técnica de vinhos e substituir o compartilhamento fixo por um botão inteligente que utilize a Web Share API nativa com fallback para cópia de link na área de transferência.

## Requirements
- SHARE-01
- SHARE-02
